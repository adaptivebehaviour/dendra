# dendra

Scaffolded from manifesto's `electron-fastapi` application. The collections are composed in `frontend/src/renderer/registry.ts`; the project's own
collection is `frontend/collection/` (`dendra-collection`).

The framework is vendored from manifesto release 2.5.1 in `frontend/vendor/` and `backend/vendor/`: **change manifesto and take a new release, never
edit `vendor/`**; upgrade with `update-project`.
